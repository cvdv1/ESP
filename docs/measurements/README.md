# 实测证据：ESP32-S3 八路波形采集

本目录保存 **2026-11-02 实机采集** 的原始数据、实测波形图和自动分析报告，
用于证明 README 里的预期值不是纸上推演，而是真实测到的。

## 文件清单

| 文件 | 说明 |
|---|---|
| `digital.csv` | Logic 2 导出的原始采集（**12.5 MB**，452,183 行，8 通道） |
| `waveform_overview.png` | 100 ms 全览（2 个 50 ms 时基周期），8 条通道一屏 |
| `waveform_zoom.png` | 细节放大 + 抖动统计（RMT 簇 / SPI 帧 / UART 帧 / 周期抖动柱状图） |
| `analysis_report.txt` | `tools/analyze_capture.py` 的完整输出（频率/占空比/脉宽/协议解码） |
| `README.md` | 本说明 |

## 采集条件

| 项 | 值 |
|---|---|
| 硬件 | ESP32-S3（板载 FTDI），串口 COM11；逻辑分析仪：24 MHz 8 通道（CY7C68013A + fx2lafw） |
| 固件 | `la-wave-demo`，提交 `4fbf71e`（日志通道名 D0~D7） |
| 采样率 | **12 MS/s**（1 个采样点 = 83.33 ns） |
| 时长 | **634.88 ms**（≈ 12.7 个 50 ms 时基周期） |
| 触发 | FreeRun（自由采集，未按 SYNC 对齐，窗口足够长即可） |
| 接线 | 板子丝印 CH1~CH8 → GPIO4/5/6/7/15/16/17/18 → 软件 D0~D7；GND 共地 |

## 实测结论（详见 `analysis_report.txt`）

| 通道 | 实测 | 设计值 |
|---|---|---|
| D0 | **999.917 Hz**，占空比 **50.000%**，周期 sd **32 ns** | 1 kHz / 50% |
| D1 | **10.000 kHz**，脉宽 10.08~89.92 µs 扫描 | 10 kHz，10.16%~89.84% |
| D2 | 13 簇 × 16 脉冲，脉宽 **2.00→17.00 µs**，簇周期 **50.003 ms**，SYNC→首脉冲 **529.75 µs** | 2~17 µs、50 ms、约 500 µs |
| D3 | **342.9 kHz**，周期 sd **339 ns**，峰峰 6.75 µs | 250~500 kHz 且抖动 |
| D4 | 12 帧 × 13 字符，全部解出 **`ESP32-S3 LA\r\n`**，位宽 8.667 µs | 115200 8N1 |
| D5 | **1.000000 MHz**，13 帧 × 32 时钟 | 1 MHz / 32 |
| D6 | 13/13 帧解出 **`AA 55 F0 0F`** | AA 55 F0 0F |
| D7 | 周期 **50.003 ms**，高电平 10.42~10.50 µs | 50 ms / 10 µs |

**抖动对比**（工程的演示重点）：

- D0（LEDC 硬件 PWM）：周期标准差 **32 ns**（≈ 0.4 个采样点）、峰峰 84 ns；
- D3（GPIO 软件翻转）：周期标准差 **339 ns**（≈ 4 个采样点）、峰峰 6751 ns。
